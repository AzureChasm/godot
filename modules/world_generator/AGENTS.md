- World chunks are fixed 16 m cubes; distinguish them from internal sampling/meshing sections and report both honestly. The unbounded demo uses parent-owned weighted child definitions and grid or grouped Voronoi allocation with field blending. Fine cells sharing an owner form one region/template origin; grouping count is approximate. Camera movement is independent of chunk-aligned terrain refresh. Keep vertical allocation, specialized/material transitions and true streaming distinct from implemented preview behavior. Preserve runtime-only auto generation and existing demos.

- TerrainView generation is asynchronous: return means accepted, not completed. Sampling/meshing/collision-face preparation run only on workers over immutable snapshots and exclusive section buffers. Keep server/scene registration staged on the main thread, honour cancellation/latest-request publication and join on destruction. Preserve prior preview on failure. Update temporary smoke checks to await completion; no main-thread fallback. View radius and sample spacing are separate controls; retain explicit budgets and report worker wall versus CPU sums honestly.

- Surface/LOD increment: inherited base elevation is compile-time metadata for opted-in decorators, not node or scope translation. Preserve nested ravine/cave scopes. Distance LOD simplifies worker-generated section meshes with fixed borders and topology validation; sampling stays full resolution and collision follows the reduced mesh. Origin changes require a new request. Continuous reference surfaces, underground 3D allocation and moving-island ownership remain distinct future work.
